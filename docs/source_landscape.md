# 缅甸信源格局与立场对照

> 这是**背景资料**，不是评分数据源。系统当前只采集可交叉验证的新闻与全球事件库，
> 官方/军方媒体用于理解各方叙事立场，不进入风险评分。整理这份表的原因是：
> 讲"我们的数据从哪来"时，需要能说清每一种信源站在谁的角度说话。

## 一、官方系统：信息部（MOI）主导

缅甸的官方新闻体系由信息部统管，覆盖通讯社、报刊、广播电视和数字平台：

| 类别 | 机构 / 产品 | 说明 |
|---|---|---|
| 通讯社 | 缅甸通讯社（Myanmar News Agency） | 官方国家通讯社，国内新闻常由它供给官方报纸 |
| 官方报刊 | 《缅甸之光》Myanma Alinn | 缅文，1914 年创刊，历史最久 |
| 官方报刊 | 《镜报》Kyemon / The Mirror | 1992 年复刊的官方日报 |
| 官方报刊 | 《全球新光报》Global New Light of Myanmar | 英文，前身《劳动人民日报》，主要英文官方喉舌 |
| 广电 | MRTV（Myanma Radio and Television） | 信息部直属，含 MRTV-HD、MRTV-News、Hluttaw 议会频道、Myanmar International 等 |
| 广播 | 缅甸广播电台（Myanmar Radio / BBS） | 缅语、英语及多种少数民族语言广播 |
| 数字 | MOI 官网 moi.gov.mm | 官方信息枢纽，也会发布官报内容 |
| 数字 | MRTV 官网 mrtv.gov.mm | 电视广播在线直播与新闻 |
| 数字 | 缅甸数字新闻 MDN（mdn.gov.mm） | 新闻与期刊企业（NPE）2018 年上线的数字门户 |

**叙事的立场特征**：以政策发布、领导人活动、官方统计数据为主；对冲突的表述通常是
"安全行动""依法处置"，系统性回避军方失利与平民伤亡。适合用于核实**政策原文和法定通告**，
不适合用于估计**冲突强度**。

## 二、军方系统：Tatmadaw（独立于信息部）

军方拥有独立于文官政府信息部之外的媒体网络，需要单独审视：

| 机构 / 产品 | 说明 |
|---|---|
| 妙瓦底集团（Myawady Group） | 军方媒体分支，含《妙瓦底日报》Myawady Daily、妙瓦底电视台 |
| 国防军总司令部的官方渠道 | 军方声明、战报的主要发布口 |

**叙事的立场特征**：强调军事行动合法性与战果，淡化自身伤亡与对平民的影响。
与信息部系统互为补充但口径不完全一致——同一事件在两者之间的表述差异本身是研究素材。

## 三、独立与民族媒体

| 媒体 | 归属 / 视角 | 在本系统中的角色 |
|---|---|---|
| The Irrawaddy（伊洛瓦底） | 流亡独立媒体，立场反军政府 | 英文新闻源（已接入） |
| Kachin News Group | 克钦独立媒体，克钦视角 | 英文新闻源（已接入） |
| DVB（民主缅甸之声） | 流亡独立媒体 | 无可用 RSS，已停用 |
| Frontier Myanmar | 独立深度报道 | 403 拒绝访问，已停用 |
| SHAN News / Narinjara / BNI | 掸族、若开族、少数民族网络 | 403/404/连接失败，未接入 |

**老实说**：独立媒体同样有立场。Irrawaddy 对冲突事实的报道通常更及时、更具体，
但对军方行为的描述带有明确倾向；Kachin News 突出克钦邦处境，对其他地区覆盖有限。
**"独立"不等于"中立"，"官方"也不等于"准确"——两边都要读，结论才稳。**

## 四、国际源（当前主力）

| 来源 | 提供什么 | 立场特征 |
|---|---|---|
| GDELT | 全球媒体事件抽取（行为体、事件码、坐标、报道量） | 反映"全球媒体的关注度分布"，本身带报道偏差 |
| Google News 聚合 | 中英文多家中外媒体标题与摘要 | 聚合结果偏向英文主流媒体与部分中文媒体 |
| UN News 中文 | 联合国官方新闻 | 国际组织口径，量少但权威 |

## 五、我们系统的取舍（2026-10-22 实测）

官方/军方渠道的可达性实测结果：

| 渠道 | 实测结果 | 处理 |
|---|---|---|
| MOI RSS（moi.gov.mm/rss.xml） | HTTP 200，10 条，**最新 2020-06-28**（停更六年） | 不接入 |
| MOI 官网首页 | HTTP 200，无 RSS 列表 | 仅作人工引用 |
| MDN（mdn.gov.mm） | HTTP 200，内容为缅文 | 不接入（现有 NER/情感链路不支持缅文） |
| GNLM（gnlm.com.mm） | HTTP 403（WAF 拦截） | 不接入 |
| MRTV | SSL 握手失败 | 不接入 |
| Myawady | SSL / 连接失败 | 不接入 |
| Myanma Alinn | 连接失败 | 不接入 |

**为什么不用官方源算风险分**：官方报道会系统性淡化冲突，如果把它混进"冲突频次"
指标，分母变大、分子不变，风险分会被系统性压低。这属于用数据制造偏差，不是增加信源。

## 六、立场差异怎么处理：三个可落地的方法

1. **分层标注**：给每条新闻标 `官方 / 军方 / 独立 / 国际` 立场，展示来源构成，
   而不是混在一起只给一个数。
2. **多源交叉验证**：同一主题被不同立场来源同时报道才更有把握；只有单一立场报道时，
   标注"单源未互证"。
3. **敏感性分析**：同一窗口按信源子集分别重算（全部 / 仅官方+国际 / 仅独立+国际），
   看结论是否随信源选择翻转。差异小说明结论稳健，差异大说明结论依赖信源——
   这本身就是值得写进报告的研究发现。

> 当前代码事实：文本指标按"命中条数 / 总条数"计算，**每条新闻等权，没有来源权重**；
> 地图的事件密度只来自 GDELT，不使用我们爬取的新闻。若后续引入来源权重，
> 应做成显式配置并在报告中说明口径，避免"偷偷降权"。

## 七、如果以后要接官方源

优先级建议：
1. **GNLM 英文官报**——立场最"官方"，但需绕 WAF（403），可用浏览器渲染或代理池尝试
2. **MDN 数字新闻**——有结构，但需补缅文分词与缅文情感能力
3. **MRTV / Myawady**——SSL 证书与网络问题，需单独网络诊断

接入后也建议**只入"官方叙事对照"数据集**，与正式评分链路隔离，避免口径污染。
