# 数据标注指南

> 面向：负责专家知识搜集与标注的团队成员（无需任何计算机基础）
> 版本：2026-07 | 本文档把所有术语都解释了一遍，遇到看不懂的词可先查文末"术语小词典"

---

## 零、先花 3 分钟搞懂我们要做什么

我们的系统是一个"会自动读新闻的 AI"。它能自动从新闻里圈出**地名、机构名、人名、事件类型**——这个"圈词"能力在计算机里叫 **NER**（全称"命名实体识别"，可以理解为"AI 自动划重点"）。

**但 AI 圈得准不准，需要人来当"阅卷老师"。** 阅卷需要一份"标准答案"——由人工逐字核对过的圈词结果，这份标准答案就叫**金标准**（gold standard，意思：像黄金一样可靠的答案）。

你们做的事就是：**给 AI 出考卷 + 写标准答案**。

---

## 一、我们有两条不同的任务线（先认准自己在做哪条）

| | 任务 A：历史事件整理 | 任务 B：NER 圈词标注 |
|---|---|---|
| 通俗理解 | 给缅甸 2020 年以来的大事记"编年表"补充条目 | 给一篇新闻手工"划重点"，作为 AI 的标准答案 |
| 一条记录长什么样 | 一件事的 7 个"表格栏目"（日期、类型、参与方……） | 一篇新闻原文 + 你圈出来的所有重点词 |
| 数量目标 | 新增 50～70 条 | ≥ 50 篇文本 |
| 用途 | 驱动系统里的历史时间线图表 | 给 AI 的圈词能力打分（及格线见术语词典"F1 分数"） |

> ⚠️ 最简单的区分办法：一条记录里如果有 `date`（日期）和 `severity`(严重程度) 这两个栏目，就是任务 A；如果有 `text`（原文）和 `entities`（圈出的词），就是任务 B。

## 二、文件格式扫盲：什么是 JSON？

标注结果要存成 **JSON 文件**（读作"杰森"，后缀 `.json`）。别被名字吓到，它就是一种**用大括号表示"一张卡片"、用方括号表示"一摞卡片"的纯文本格式**：

```json
[                       ← 方括号：一摞卡片（一个文件装很多条记录）
  {                     ← 大括号：一张卡片（一条记录）
    "栏目名": "内容",    ← 一行一个栏目，注意：冒号、引号、逗号都是英文半角！
    "日期": "2026-03-28"
  },                    ← 卡片之间用英文逗号隔开
  { "第二张卡片": "..." }
]                       ← 最后一张卡片后面不加逗号
```

**三条保命规则**（违反任何一条文件就打不开）：
1. 所有引号、冒号、逗号、括号必须用**英文半角**输入法打出（中文的"：""，"会导致文件损坏）
2. 最后一张卡片后面**不能**多一个逗号
3. 保存时选 **UTF-8 编码**（一种通用的文字编码方式，不选它中文会变成乱码）。用 Windows 记事本编辑时，点"另存为"，底部的"编码"下拉框选"UTF-8"即可

> 💡 建议：不要用 Excel 编辑 JSON。推荐直接用记事本，或者把写好的内容粘贴到在线校验网站（搜索"JSON 在线校验"）检查一下有没有格式错误。

## 三、任务 A：历史事件整理格式

每条大事一张"卡片"，7 个栏目，全部放进同一个文件：

```json
{
  "date": "2026-03-28",
  "event_type": "军事冲突",
  "actors": ["缅甸国防军", "克钦独立军"],
  "location": "克钦邦",
  "severity": 4,
  "description": "缅军对克钦邦发动新一轮攻势，平民被迫转移",
  "source": "新闻报道"
}
```

### 各栏目怎么填

| 栏目 | 怎么填 | 举例 |
|---|---|---|
| `date` 日期 | 格式 年-月-日（月和日不足两位要补 0）。只知道月份就写当月 1 日，并在描述里注明"具体日期待考" | `"2026-03-01"` |
| `event_type` 事件类型 | **目前只能从下面 14 个里选 1 个**，自己要发明新类型要告诉技术团队 | 见下方清单 |
| `actors` 参与方 | 用方括号列出所有参与方，用**通用名称**（见第五节） | `["缅甸国防军", "中国"]` |
| `location` 地点 | 一个地点。优先写邦/省/城市；全国性事件写"全国"；查不到写"未公开" | `"掸邦"` |
| `severity` 严重程度 | **1～5 的整数**：1 轻微 / 2 一般 / 3 较大 / 4 严重 / 5 极严重（重大伤亡或改变政局） | `4`（注意：数字不加引号） |
| `description` 描述 | 一句话客观陈述，不超过 50 字，不加个人评论 | 见上方例子 |
| `source` 资料来源 | **只能从 5 个里选 1 个**：官方 / 新闻报道 / 全球新闻 / 国际组织 / 研究报告 | 见下方说明 |

**事件类型 14 选 1 清单**：军事冲突 / 军事 / 武装 / 政变 / 政治 / 选举 / 抗议 / 暴力镇压 / 外交 / 经济 / 经济制裁 / 人道危机 / 公共卫生 / 自然灾害

**资料来源说明**：来自学术论文、智库报告的，`source` 填"研究报告"——**这正是本次搜集的重点**，请优先从论文中挖掘事件。

## 四、任务 B：NER 圈词标注格式

一条记录 = 一篇新闻原文 + 你圈出的四类重点词：

```json
{
  "text": "这里粘贴新闻原文全文……",
  "entities": {
    "locations": ["缅甸", "掸邦"],
    "organizations": ["联合国", "东盟"],
    "persons": ["敏昂莱"],
    "events": ["冲突", "空袭"]
  }
}
```

四类词的意思：`locations` 地名 ｜ `organizations` 机构组织 ｜ `persons` 人名 ｜ `events` 事件类型词

### 圈词规则（重点！）

| 类别 | 自由圈，还是从固定清单选？ | 说明 |
|---|---|---|
| 地名 | **自由圈**，但必须是原文里真实出现的 | 同一地点统一用通用名（"掸邦"就都写"掸邦"） |
| 机构组织 | **自由圈** | 政府、军队、公司、媒体、国际组织都算；带英文缩写的写成"中文名（ACLED）"这种形式 |
| 人名 | **自由圈** | 只写人名本身，不带职务（写"敏昂莱"，不写"缅军总司令敏昂莱"） |
| 事件词 | **必须从固定词表里选**（21 个词，见下） | 原因见下方红字说明 |

#### 事件词固定词表（21 词）

> 冲突、战斗、空袭、武装、交火、爆炸、袭击、制裁、政变、选举、抗议、暴动、难民、停火、和谈、贸易、投资、管道、港口、铁路、经济走廊

> 🔴 **为什么事件词必须从词表选？** 因为阅卷时是把"你圈的答案"和"AI 圈的答案"**逐词对比**来算分的。AI 只认识上面这 21 个词，如果你圈了词表外的词（比如"内战"），就算圈得对也判不得分。所以：文中出现但词表没有的事件词，**先不圈**，单独记在备注里发给技术同学，由技术侧决定要不要扩词表。
>
> 以样例"事件1.json"为例：`冲突`✅ `袭击`✅ `政变`✅ `空袭`✅ 在词表内可以圈；`内战`❌ `大规模屠杀`❌ `外交斡旋`❌ 不在词表内，请记入备注。

## 五、通用规范：同一个东西只许有一种写法

为避免"同一机构三种写法"导致统计失真，请遵守：

| 类别 | 规则 | 例子 |
|---|---|---|
| 国家 | 用中文通名 | "中国"（不写"中华人民共和国"） |
| 缅甸地名 | 用通行中文译名 | "掸邦""仰光""内比都" |
| 机构 | 全文统一用一种写法 | "武装冲突地点与事件数据项目（ACLED）" |
| 武装组织 | 用通用简称 | "克钦独立军""人民防卫军" |

## 六、交作业须知

1. **一条任务线交一个 JSON 文件**（一个文件里装很多条记录），**不要**每条记录存一个文件
2. 文件命名：`历史事件_批次1.json` / `ner标注_批次1.json`
3. 保存时确认编码是 **UTF-8**（见第二节第 3 条）
4. **每批先交 3～5 条**给技术同学确认格式，确认没问题再批量做——上次"事件1.json"已确认通过 ✅

## 七、进度安排

- **周五前**：任务 A（历史事件）交付 50～70 条，优先级最高
- 任务 B（圈词标注）可以和任务 A 并行做，两件事互不影响
- 另一项工作"给 AI 的分析结果打分"**不需要等**上面两项做完；但它要等技术同学配置好大模型后才能开始，届时会另行通知

## 附：术语小词典

| 术语 | 大白话解释 |
|---|---|
| **JSON** | 一种纯文本的"表格"文件格式，用大括号做卡片、方括号做一摞卡片，后缀 `.json` |
| **字段 / field** | 卡片上的一个"栏目"，比如日期、地点 |
| **数组 / array** | 方括号里的一串并列内容，比如一摞卡片、多个参与方 |
| **UTF-8** | 一种国际通用的文字编码方式；保存时不选它，中文会变乱码 |
| **NER** | "命名实体识别"，即 AI 自动从文章里圈出地名、人名、机构名的能力 |
| **实体 / entity** | 被圈出来的重点词本身（一个地名、一个人名……） |
| **金标准** | 人工逐字核对过的标准答案，用来给 AI 阅卷 |
| **F1 分数** | 给 AI 圈词能力打分的综合分（0～1 之间）。圈多了、圈漏了都扣分；我们的及格线是 0.70 |
| **词表** | 系统预先规定好的一组可选词，事件词必须从中选择 |
| **大模型 / LLM** | 能理解和生成文字的 AI（比如帮我们写新闻分析的"智谱"模型） |
