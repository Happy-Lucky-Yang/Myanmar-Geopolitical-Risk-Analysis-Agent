# 项目独特优势与中期答辩说明

> 面向评审老师的一份说明：**本项目为什么不是"一个大模型对话框套了个网页壳"**，
> 以及它在学术、方法与工程上究竟"有意义"在哪里。文中每一项能力都对应仓库中可复现的代码、
> 文档或测试，欢迎现场核验。
>
> **当前口径更正**：正式日风险仍为 risk-v2，risk-v3 是 GDELT 实验代理路径；与组长终稿的差异见 [对标矩阵](upgrade_v3.md#0-终稿对标与当前交付边界)。本轮增加个人工作区、证据研判、文献中心和 UN News 适配，功能默认关闭；数据库及真实模型联调未验收，不能称已上线。

---

## 摘要：一句话回答

> **大模型对话框**是"输入自然语言 → 概率性生成一段看起来合理的文字"，它不可溯源、不可复现、
> 不做定量空间计算、也无法区分"算出来的"和"编出来的"。
>
> **本系统**是一条"真实多源数据 → 结构化清洗 → 定量地理空间算法 → 可证伪评测 → 可视化与预警"的
> **确定性、可复现、可审计**的科学计算流水线。大模型在本系统里用于**链式推理和证据型研判等可选环节**，
> 把它关掉，风险评分、地图、趋势、预警依然完整运行。

一句话：**我们的价值不在"能回答缅甸问题"，而在"每个回答都可溯源、可复现、可证伪，并诚实标注已知与未知"**——
这恰恰是通用对话框最缺乏、也是科研训练最核心的素养。

## 一、本质区别：确定性科学计算 vs 概率性文本生成

| 维度 | 通用大模型对话框 | 本系统 |
|------|------------------|--------|
| 数据来源 | 训练语料，**不可溯源**、有知识截止日期 | **7 类真实数据源**实时采集，每条带来源/URL/时间戳/健康状态 |
| 结果性质 | 概率性生成，同一问题多次问**答案可能不同** | 确定性计算，**同一输入 + 同一数据必得同一输出**（可一键复跑） |
| 空间分析 | 只能"描述"地理概念 | 对真实经纬度做**地缘位势 1/d²、Moran's I / LISA / Getis-Ord Gi\* 空间自相关、KDE 核密度**计算 |
| 可复现/可审计 | 不可复现、无版本、无审计 | 输入/代码/依赖包 **SHA-256 指纹** + 算法版本号 + **自动化回归**（最新数量与跳过原因见 [验收说明](acceptance.md)） |
| 数据诚信 | 会"一本正经地编造"（幻觉） | **真实 0 与缺测 null 严格分离**、代理值显式标注且**不进入正式评分** |
| 效果评测 | 无客观评测，"感觉挺准" | 人工金标准 + **分组留出集** + micro-F1 + **禁止调参污染留出集**协议 |
| 大模型角色 | **系统本体** | 一个被 schema 校验/超时/降级/缓存隔离约束的**可选增强环节** |

**现场可验证的对照**：问对话框"缅甸某省今天的风险分是多少"，它会编一个数字，无来源、无法复现、下次再问可能变；
本系统 `/dashboard` 返回的每一个分数都绑定**去重文章、发布业务日、指标贡献、覆盖率、算法版本、数据来源**，
运行 `python scripts/evaluate_acceptance.py ...` 可当场复算，指纹一致。

## 二、七个"对话框做不到"的技术内核

### 2.1 定量地理空间算法（本项目最硬的差异化）

这是区域国别研究 × 地理信息科学的交叉核心，**大模型无法对真实数据"计算"这些，只能"描述概念"**：

- **地缘位势模型（potential-v3，距离衰减）**：某省地缘位势 = Σ(战略中心权重 / 距离²) × 风险分。5 个战略中心
  （中缅边境**瑞丽**、**皎漂港**、**内比都**、泰缅边境**妙瓦底**、**仰光**）按组长权重表 **3:2:1 归一**
  （皎漂/瑞丽 0.30、内比都 0.20、妙瓦底/仰光 0.10，和=1.0，`validate_center_weights()` 断言），并以 Spearman ρ
  做**距离敏感性**检验。这是地理学第一定律（距离衰减效应）的显式数学建模，需要真实经纬度与距离计算。→ `analyzer/geo_potential.py`
- **空间自相关（moran-v3 / lisa-v1 / gistar-v1）**：全局 **Moran's I** + 局部 **LISA**（HH/LL/HL/LH 四分类）+
  **Getis-Ord Gi\*** 冷热点；三套空间权重矩阵（Queen 邻接 / 距离阈值 / 距离衰减）做敏感性，行归一、
  **999 次固定种子（42）单侧置换检验**、至少 8 个有效区域才报显著性，回答"风险是否在空间上聚集、聚集在哪"。
  这是**空间统计学的假设检验**，不是文本生成。→ `analyzer/spatial_analysis.py`
- **KDE 核密度估计**：LAEA 等面积投影、固定公里带宽、以"加权事件 /（平方公里·天）"计绝对密度、跨窗口按天归一
  并用共同色标、国界掩膜。把离散事件点渲染成连续密度面。→ `analyzer/event_density.py`
- **真实行政边界归属**：GADM 4.1 缅甸四级行政边界 + EPSG:4326 坐标归属 + 事件发生地匹配；**边界歧义列为"未定位"
  而不硬猜**，无样本省份灰显。→ `data/admin_boundaries.py`

### 2.2 多源异构数据工程（对话框根本没有"数据采集"这一层）

大模型的知识**冻结在训练截止日期**，无法反映缅甸最近 7 天的真实事态。本系统有一整套采集工程：

- **7 类数据源**：缅华网（中文）、GDELT（CSV 直连主通道 + DOC API 备用）、Google News 双语聚合、
  Irrawaddy/Frontier、World Bank 夜光、World Bank 经济、**482 条历史事件集**（2020–2025）。
- 每个源带**健康监控**（成功率/降级持久化）、**限速退避**（GDELT 每 5 秒一请求 + 抖动）、**去重水位线**、
  **事务性事件累积库**（历史不自动删除）。→ `data/source_health.py`、`data/event_store.py`
- 诚实说明"数据不同步是正常现象"（爬取数据不入 git），演示前需提前积累或打包共享。

### 2.3 数据诚信契约：对"AI 幻觉"的工程化抵抗（最能体现科研素养）

对话框的本质是"生成看起来合理的内容"，**无法区分"我算的"和"我编的"**。本系统用契约把这条线画死：

- **真实 0 与缺测 null 严格分离**：没有数据 ≠ 低风险；缺测返回 null 并灰显，**绝不补零**。
- **数据域标记**：`live / existing / manual / demo / legacy` 互不混淆；手工分析与 demo **绝不混入正式历史**。
- **占位指标**（夜光/难民）值为 0 时，其权重**按比例重分配**给有效指标，不用"僵尸权重"稀释评分。
- **quality 门控**：外部数据必须显式声明 `quality == 'observed'` 才进入正式评分；未声明的代理值**不评分**。
- 每次查询随结果返回 **indicator_coverage（覆盖率）与 algorithm_version（算法版本）**。
- WB 电力代理夜光、经济推断难民——**明确标注为"代理估算"，不冒充真实遥感/难民观测**。

> 这套契约正是"有意义"的关键：它让系统的每个数字都带着**可信度标签**，而不是把估算和观测混为一谈。

### 2.4 可证伪的评测方法论（对话框无法自评准确率）

- **人工金标准**：薛雨恬标注 60 条 · 705 实体，舒媛媛格式校对。
- **分组留出（grouped_partition）**：按人工 `event_group_id` 划分校准/留出集（至少 5 个事件组），
  **防止"同一事件的多篇报道"既训练又测试造成的假独立**。
- **micro-F1 精确匹配**评测，报告 P/R/F1 + 每类型细分 + 后端 + 分区指纹。
- 明文协议：**"留出集不得用于调词典或参数"**；基线冻结回归保护（frozen baseline test）。
- 本轮词典扩充后**诚实标注**：批次 1 已从潜在留出降级为"被词典参考过的校准基线"，正式 ≥70% 验收需
  **未参与调参的 batch2 独立留出集**。

> 我们把申报书的"准确率 ≥70%"变成一个**可复现、可证伪、带数据指纹**的评测协议；即使当前未达标，
> 也如实报告 `status = not_accepted`，而不是"跑个 demo 说很准"。

### 2.5 统计严谨的时序预测与异常检测

- **真实日历窗口**（Asia/Yangon 连续日历，缺测断线不补零）。
- **滚动回测**：末值 / EWMA / 线性回归三候选，至少 **56 个有效日 + 4 个七日回测窗**后按 MAE/RMSE 选择模型，
  **不以复杂度或样本内 R² 宣称"升级有效"**。
- **外推门槛**：至少 14 有效日 + 80% 覆盖 + 截止日有真实观测，否则返回空预测与原因。
- **异常检测**：历史中位数 / MAD（尺度 `max(1, 1.4826×MAD)`，绝对偏差/尺度 > 3.5 才标记），
  **仅用当前点之前 28 个日历槽，不使用未来数据**。
- **R² 仅描述样本内拟合优度**，明确声明"不是显著性检验或预测置信度"。

### 2.6 生产级工程治理（对话框没有协作、事务、备份、权限这一整套）

- SQLAlchemy 2 + psycopg 3 + Alembic 迁移；文件后端默认，**PostgreSQL 失败绝不静默回写 JSON**。
- **JobQueue 行锁领取 + clock_timestamp 心跳 + 租约令牌隔离**；worker 失租不写业务；重试命中同 `job_id`
  返回首次快照，避免结果漂移。
- `import_data.py` 默认 **dry-run**，`apply` 需 `IMPORT_DATABASE_URL` + 精确库名确认，逐批次事务 + 幂等。
- `database_ops.py` 四动作默认预演，`apply` 需 `DATABASE_TOOL_URL` + `--confirm-database`；产物只写授权根目录下
  全新单层目录，拒绝链接与越界；`pg_dump` + **SHA-256 清单校验**；恢复仅面向 `_test` 隔离库。
- **密钥红线**：`config.yaml` 永远占位符，真实密钥只写 `.env`（.gitignore 拦截），运行时环境变量覆盖。
- 日志只写异常类型，**不泄露用户私密文本、供应商回显或连接串**。

### 2.7 理论驱动的九指标风险体系 + 可证伪归因（本轮 v3 升级）

对话框给不出"权重从哪来、贡献怎么分解"的可审计链条。本系统把地缘理论落成可复现的量化体系：

- **risk-v3 九指标三层体系**：要素层按**地缘关系 0.6 / 地理环境 0.2 / 地缘结构 0.2**（比 3:1:1，源自胡志丁等
  2013 三要素框架 + 2014 权力等级论，各层判断矩阵一致性比率 **CR=0**）逐级归一到九项全局权重（和=1.0）。
  其中中缅/中美/周边/西方/制裁五项由 `analyzer/geo_indicators.py` 从 GDELT **Goldstein 报道量加权净值 + CAMEO 分类**派生，
  带 `observed/derived/missing` 质量标记，**缺测不补零、不稀释**。→ `analyzer/risk_scorer.py`（`algorithm_version="risk-v3"`）
- **Shapley 精确归因（shapley-v1）**：对九指标做 **2⁹ 子集精确枚举**（无近似），带三恒等式断言
  （ΣC(k)=1 / Σw·ΔZ=ΔR / Σφ(k)=R，容差 1e-6）；归因文本模板层**过滤"导致/引起/造成"因果动词**——
  输出是**贡献分解，不是因果结论**，把"可证伪"落到归因文本层面。→ `analyzer/diagnostic.py`
- **8 节点行为体关系网络（actor-network-v1）**：MMR/CHN/USA/EUU/THA/IND/BGD/LAO 有向加权（Goldstein 净值），
  分合作/冲突层，四断言（节点数/边权范围/无自环/模块度区间）；**输出不进入风险合成**，避免与九指标关系类重复计量。
- **文献知识库一期（kb-index-v1）**：把文科团队整理的 **645 篇权威文献**总表结构化为可检索索引，
  并按"研究主题类别"精确映射到智能计算四模块与九指标（如"地缘位势与影响力测算"→模块一），
  让每个技术模块都能召回支撑文献——**这是跨学科协作落到代码里的证据**。→ `analyzer/knowledge_base.py`

## 三、大模型在本系统中的准确定位

**LLM 只出现在链式推理（`analyzer/chain_reasoner.py`）这一个环节**：事件识别 → 影响分析 → 趋势研判 → 建议生成，
逐步注入前序结果。而且它被**层层约束**：

- 统一提供商配置 / 超时 / 重试；**占位密钥不触网**；失败不进入成功缓存。
- 每一步按对应 schema 检查字段与类型，返回 `schema_completeness`（**明确声明这不是"正确率"**）；
  调用/解析/字段校验失败时**显式标记失败并停止后续步骤**。
- 缓存按 **提供商 / 模型 / 提示词 / schema 版本 / 输入** 隔离。
- 对话页强制分四段展示：**结论摘要 — 证据 — 不确定性 — 技术详情**，结论**须人工依据证据复核**。
- **LLM 缺失时系统完整运行**（对应接口返回可见降级状态）——这从工程上证明 LLM 是"可选增强"，不是系统本体。

> 换句话说：风险分、地图、趋势、预警、网络分析**全部来自确定性算法，不由 LLM 生成**；
> LLM 只是流水线末端一个被证据、schema 与审计包裹的"研判助手"。

## 四、诚实面对三项短板（这恰恰是科研训练的价值所在）

我们不粉饰。以下三项**全部如实登记在 `docs/acceptance.md` 与 `README.md`**，且都属"依赖外部条件"的门控项。

### 4.1 NER 未达申报书承诺的 70%

- **现状**：批次 1（60 条）在**领域 gazetteer 词典后端**下 micro-F1 = **0.494**（P 0.770 / R 0.363），`status = not_accepted`。
- **根因（关键）**：评测环境 **paddle 损坏使 LAC（百度中文 NER）无法在运行时导入**——这是环境/后端问题，不是算法链路问题；
  LAC 路径的正确性由 FakeLAC 单测证明（正确映射 PER/ORG/LOC 与事件）。
- **本轮实证（三后端 A/B，非空谈）**：在 60 条人工金标准上逐一实测中文后端——
  ① **LAC/paddle 经诊断在 py3.12+Windows 不可行**（LAC 仅有 2.1.2、需 paddle2 的 `fluid`；paddle 2.6.2 无 cp312 Win 轮子致 `libpaddle.pyd` 缺失；paddle 3.0 有 cp312 轮子但删除了 `fluid`）；
  ② **通用 jieba 词性标注 micro-F1 仅 0.421**（P 0.416，过度标注致精确率崩塌）；即便只在词典零命中时用 jieba 兜底，也在 4 段文本上**净增 34 FP / 0 TP**，把整体拉低到 **0.478**；
  ③ **领域 gazetteer 词典 0.494（P 0.770）为最优**。
- **据此的工程决策**：以 gazetteer 词典为**默认中文回退终点**（精确率优先——风险系统里假阳性会误导决策者），jieba 保留安装（满足必需依赖契约）但**降级为构造参数 `NERExtractor(jieba_fallback=True)` 显式开启**的域外召回实验选项。
- **纪律性**：gazetteer 仅纳入任何缅甸地缘系统都应具备的**通用地理常识**（邻国 / 主要城市 / 常见机构 / 历史领导人），**未抄入金标准的复合标签或文章专属人名**，`persons` 精确率保持 **1.000（无人名过拟合）**；相较扩充前 F1 0.427，**召回率 +0.070、F1 +0.067**。
- **正式 ≥70% 验收路径**：需 LAC 在兼容环境（如 py3.10/Linux）恢复或接入云端中文 NER，并须用**未参与调参的 batch2 独立留出集**评测。

### 4.2 夜光 / 难民 / 中缅贸易为代理或缺测

- **夜光**：申报书承诺 NASA VIIRS 原始栅格；当前用 **World Bank 电力可及性代理**，明确标注"代理估算"，
  **不进入正式评分/多模态序列**。真实 VIIRS 需 GeoTIFF 月度合成数据（门控，待老师提供）。
- **难民**：当前为**经济推断占位**，无 UNHCR 真实数据源，同样不进正式评分。
- **中缅贸易**：申报书承诺**月度双边贸易变化**；当前仅采集到 WB **年度** `trade_pct_gdp`（贸易开放度），
  **口径不同、未纳入风险模型**（v3 九指标的"中缅关系"维度用 GDELT Goldstein 报道量净值，非贸易额），
  已在 README"双边关系评估模块"如实登记；接入需 UN Comtrade / 中国海关月度双边数据（门控）。
- **关键立场**：项目**刻意拒绝用代理值伪造真实观测**。宁可写"缺测/代理/暂缓"，也不制造"看起来完成了"的假象——
  这正是 2.3 数据诚信契约的体现。

## 七、预期追问与标准回答（Q&A）

**Q1｜这和直接问 ChatGPT/文心一言有什么区别？**
A：三点本质区别。① **数据来源**——我们从 7 类真实源实时采集缅甸最近事态，大模型知识冻结在训练截止日期且不可溯源；
② **确定性**——我们的风险分/地图/趋势是可复现的定量计算，同样输入必得同样输出，大模型每次生成可能不同且无法审计；
③ **空间科学**——地缘位势 1/d²、Moran's I、KDE 是对真实经纬度的空间统计计算，大模型只能"描述概念"无法"计算真实数据"。
在我们系统里，LLM 只是链式推理一个被 schema 校验和证据包裹的**可选环节**，关掉它系统照样完整运行。

**Q2｜NER 准确率没到 70%，是不是没做出来？**
A：代码链路完整且正确（LAC 路径由单测证明）。我们**没有停在“装个 jieba 就行”的口头承诺**——本轮在 60 条人工金标准上
实测三种后端：LAC/paddle 经诊断在 py3.12+Win 不可行；通用 jieba 词性标注仅 0.421（精确率崩到 0.416）；领域 gazetteer
词典 0.494（P 0.770）最优。据此把 gazetteer 定为默认后端、jieba 降为显式 opt-in（实测它作兜底会净增 34 FP/0 TP）。
扩充通用词表把 F1 从 0.427 提到 0.494 且 persons 精确率保持 1.0（无过拟合）。**我们选择如实报 `not_accepted` 而非粉饰**——
可证伪评测协议 + 用数据否决“想当然”的后端，正是本项目区别于对话框的地方。正式 ≥70% 验收还需兼容环境恢复 LAC 与 batch2 独立留出集。

**Q3｜夜光、难民、贸易数据是不是假的？**
A：我们**明确标注它们是代理/缺测，且刻意不让代理值进入正式风险评分**。真实 VIIRS 栅格、UNHCR 难民、
中缅月度双边贸易分别需要外部数据源（老师提供 / 接口授权），属门控项。宁可写"缺测/暂缓"也不伪造——
这是数据诚信契约，也是对 AI 幻觉的工程化抵抗。

**Q4｜Neo4j 没部署，知识图谱算完成了吗？**
A：图谱代码与 34 节点 / 35 关系种子数据完整；**NetworkX 内存网络分析（中心性/社区）不依赖 Neo4j，已可演示**。
Neo4j 只是可选的持久化/可视化后端，激活指南已写入 README，部署实例属门控项。

**Q5｜项目的工作量和创新点到底在哪？**
A：**创新点**——① 把定性地缘判断变成**可量化、可复现、可证伪**的计算流水线（区域国别 × GIS × NLP 交叉）；
② **数据诚信契约**（真实 0 / 缺测 null / 代理标注 / quality 门控）用工程手段对抗 AI 幻觉；
③ 定量地理空间算法（地缘位势 + Moran's I / LISA / Gi* + KDE）落地到缅甸省级真实边界；
④ **理论驱动的 risk-v3 九指标三层体系**（胡志丁三要素，CR=0）+ **Shapley 精确归因**（三恒等式、禁因果动词）+
**文科 645 篇文献知识库**映射到技术模块——跨学科协作落到代码里。
**工作量**——352 项自动化测试、五层完整流水线、7 类数据源、二十多个业务 API、4 个可视化页面，
以及完整的数据库迁移 / 任务队列 / 备份恢复 / 权限治理。

## 八、结论

本项目不是"给大模型套了个网页壳"，而是一个**以大模型为可选增强、以确定性数据-算法流水线为主体、
以数据诚信和可证伪评测为底线**的区域国别地缘环境智能计算系统。

它把"缅甸地缘风险"这个原本依赖专家定性判断的问题，转化成一条**可采集、可计算、可复现、可审计、可证伪**的
科学流程；并且**诚实地标注每一处已知与未知**——这种"知之为知之、不知为不知"的工程与科研态度，
正是它区别于任何一个"大模型对话框"的根本所在，也是它作为大创项目最有意义的地方。
