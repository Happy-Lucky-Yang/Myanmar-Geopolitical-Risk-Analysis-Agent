## 第一章 绪论

### 1.1 研究背景
- 缅甸地缘政治环境的复杂性与中缅关系的重要性
- "一带一路"中缅经济走廊的战略价值
- 2021年政变后缅甸局势的持续动荡

### 1.2 研究意义
- 理论意义: 多源数据融合在地缘风险分析中的应用
- 实践意义: 为中方决策提供量化参考工具

### 1.3 国内外研究现状
- 地缘政治风险评估方法 (定性 vs 定量)
- 遥感夜光数据在冲突研究中的应用
- NLP/大模型在事件分析中的进展

### 1.4 研究内容与技术路线
- 系统架构设计 (五层技术路线图)
- 创新点概述

## 第二章 数据采集与清洗

### 2.1 多源数据采集
- 缅华网/英文媒体新闻爬取 (Python + BeautifulSoup)
- GDELT 全球事件数据库 API 对接
- NASA VIIRS 夜间灯光遥感数据 (World Bank 代理)
- World Bank 宏观经济统计数据

### 2.2 数据清洗与预处理
- 文本去重、去噪、编码统一
- 时间戳标准化
- 缺失值处理策略

### 2.3 数据质量保障
- 可信度标记规范 (官方/估算/插补/合成)
- 缓存与更新策略

---

## 第三章 智能计算引擎

### 3.1 命名实体识别 (NER)
- LAC 中文分词 + 词性标注
- 英文 NER (spaCy/正则)
- 实体标准化与消歧

### 3.2 多语言情感分析
- 中文: SnowNLP
- 英文: VADER
- GDELT tone 融合
- 冲突关键词增强

### 3.3 风险评分模型
- **risk-v3 九指标三层体系**（要素层：地缘关系 0.6 / 地理环境 0.2 / 地缘结构 0.2）
- 九项全局权重：冲突频次/中缅关系/中美博弈/事件严重度/夜光变化/周边邻国关系/流离失所/西方关系/国际制裁
- GDELT 派生五项双边/结构指标（Goldstein 报道量加权净值 + CAMEO 分类）
- **动态权重归一化**（缺测指标不稀释、不补零）
- 旧 `risk-v2` 五维路径保留作历史对照

### 3.4 大模型辅助分析
- 提示词工程 (prompts.py)
- 结构化 JSON 输出解析
- 链式推理 (4步: 事件识别→影响分析→趋势研判→建议生成)

## 第六章 可视化与输出

### 6.2 趋势预测图表
