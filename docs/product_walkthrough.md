# 产品逐页说明（面向汇报与验收）

> 这份文档按“客户参观”的顺序走一遍产品：每一页解决什么问题、页面上每一处文字在说什么、
> 数字从哪来、哪些话能说、哪些话不能说。文案均为 2026-10-22 实测抓取，标点与括号照原样保留。

## 零、产品定位（开场 30 秒）

**一句话**：这是一个把缅甸相关新闻、全球事件库和世界银行数据，加工成**可追溯、可拆解、可质疑**的地缘风险观测台。

**三个关键词**：
1. **可追溯**——每个分数都能点进去看是哪几条新闻、哪几个指标、哪一版权重算出来的
2. **不造假**——缺数据就显示缺测，不用 0 填充、不用旧值顶替、不硬凑预测
3. **有边界**——页面上大量灰色小字在主动声明“这个数不能推出什么”

**技术栈**：Flask + 原生 JavaScript + ECharts + Folium/Leaflet；分析层 NumPy/SciPy/networkx/shapely/pyproj；
大模型走智谱 GLM 与 DeepSeek 双提供商路由。

### 4. 全站反复出现的四类“边界声明”

这些灰色小字不是装饰，是产品的方法论立场，汇报时可以专门讲：

1. **风险分不是概率**——`风险分（0-100，非发生概率）`
2. **贡献不是因果**——`贡献不代表因果作用`、`描述性空间相关，不代表因果关系`
3. **缺测不是零**——`缺测不能解释为零风险`、`缺失不补零`
4. **报道不是现实**——`事件需被媒体报道才会进入；热区反映报道关注度，不等于实际冲突密度`

## 二、文本研判页 `/`（对话分析 → 文本分析）

### 这页解决什么问题

手上有一条缅甸新闻，想知道：里面有哪些实体、情绪多负面、风险多高、大模型怎么解读、每个指标贡献了多少分。

### 页面逐区域说明

**标题区**
- 小标签：`TEXT ANALYSIS`
- 主标题：`新闻文本研判`
- 说明：`粘贴或上传一篇缅甸相关报道，得到情感、风险、实体与贡献拆解。手工输入只作独立分析，不写入正式日风险或共享图谱。`
- 链接：`多轮追问 → 个人工作区`

**输入区**
- 工具栏标签 `分析模型`，下拉五个选项（名称 + 描述）：
  - `GLM-4-Flash（快速）` — `免费高速，适合批量初筛`（默认）
  - `GLM-4-Plus（精准）` — `深度分析，地缘推理能力更强`
  - `GLM-4-Long（长文）` — `支持 20k 上下文，适合长报告`
  - `DeepSeek-chat（极速）` — `DeepSeek 对话模型，响应极快`
  - `DeepSeek-reasoner（推理）` — `深度推理，复杂地缘分析能力更强`
- 上传按钮：`＋ 上传文件`（支持 .txt / .json / .csv / .md，可多选）
- 文本框 placeholder：`请输入或粘贴缅甸相关新闻内容，或上传文件…`
- 字数统计：`0 / 20000`
- 复选框：`启用链式推理`
- 按钮：`填充示例`、`开始分析`
- 底部小字：`模型结论须结合证据与不确定性复核；字段完整不等于结论正确。正式观测请到"态势总览"查看。`

**结果区（六张卡片）**

| 卡片 | 内容 | 实测示例 |
|---|---|---|
| 情感分析 | 大数字 = 风险值，下方 `情感分（0=负面 1=正面）`，底部标数据来源 | `65` `中风险` / `0.35` / `数据来源: SnowNLP 中文模型` |
| 风险评分 | 大数字 = 综合风险，五个指标条，顶部提示权重归一化 | `84` `高风险` / `⚡ 权重已动态归一化（部分指标暂缺）` |
| 实体识别 | 按类型分组计数 | `地名 (3)`：缅甸、掸邦、中国 / `组织 (2)`：克钦独立军、联合国 / `事件 (6)`：冲突、武装、交火、难民、停火、经济走廊 |
| 大模型分析 | 四个字段 | `事件类型` 军事冲突 / `事件摘要` / `中缅影响` / `风险提示` |
| 指标贡献分析 | 标签 `非因果`，小字 `按实际有效权重分解风险分，贡献不代表因果作用。` | `冲突频次 (65%)` → `64.72`；`舆情负面度 (35%)` → `35.28`；`🎯 主导因素: 冲突频次` |
| GDELT 全球事件指标 | 图标 `📡` | `暂无 GDELT 数据` |

**链式推理卡片**（勾选后出现）
- 标题 `链式推理`，标签 `分步逻辑`
- 说明行：`共 N 步推理（实际执行的步骤名）`，中断时追加 `· 未跑完全部 4 步，后续步骤已中断`
- 每步显示：序号、步骤名、`字段完整率 XX%（非正确率）`、该步的分析问题、结构化输出
- 四个步骤依次是：`事件识别与分类` → `影响分析` → `趋势研判` → `建议生成`
- 底部摘要行：`📋 摘要: 军事冲突 | 风险 未知`

### 数字从哪来

- 情感分：中文 SnowNLP、英文 VADER（双语感知，按 `language` 字段选引擎）
- 实体：中文 LAC（不可用时降级 jieba 词性 → 词典正则），英文 spaCy `en_core_web_sm` + **缅甸地名词典纠正**
- 风险分：冲突关键词命中率 + 情感风险值，按 config 的 `risk_weights` 加权，缺测指标剔除后权重重新归一
- 大模型：固定 JSON 契约（8 个字段），用户自定义指令只能追加“额外关注”，不能改输出结构

### 能说什么 / 不能说什么

✅ 能说：单篇新闻的结构化研判、五维贡献拆解、分步推理过程
❌ 不能说：这代表全国当天风险（页面已声明“手工输入只作独立分析，不写入正式日风险”）

  `趋势: 未计算（不能以分值高低推断趋势）` ／ `经纬度: (22.51, 93.43)`

### 数字从哪来

- **风险散点**：每省一个点，位置是省几何代表点（不是事件点）；分值 = 该省窗口内已定位事件的 CAMEO 规则烈度均值 ×100；
  半径 `6 + 归一化分 × 10`；颜色走连续色带
- **KDE 密度**：GDELT 事件坐标 → LAEA 等面积投影（`+proj=laea +lat_0=19 +lon_0=96`）→ 50km 高斯核 → GADM 国界掩膜
- 样本不足保护：窗口内有效定位事件 < 5 条直接降级不画
