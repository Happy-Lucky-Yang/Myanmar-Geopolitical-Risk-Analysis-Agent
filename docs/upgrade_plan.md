## 一、遥感升级包（团队已决议推进）

### 1.1 VIIRS 夜间灯光原始栅格接入 ——【待数据】

**目标**：用真·夜光遥感替换当前 World Bank 电力覆盖率代理指标，
升级风险评分五维中"夜光变化"维度（权重 0.20）的数据质量。

**需要向老师申请的数据**：

| 要求项 | 规格 |
|--------|------|
| 产品 | VIIRS DNB 月度合成（VNL V2 无云平均辐射值），NOAA 或 NASA Black Marble 均可 |
| 格式 | GeoTIFF（`.tif`），勿用截图/PDF |
| 范围 | 缅甸全境 |
| 时间 | 2020 年至今，**优先月度**（年度数据只能看静态差异，月度才能捕捉冲突后夜光骤降等动态信号） |
| 分辨率 | 15 角秒（约 500m）或更粗 |

**系统侧实施（数据到位后，约 1 个工作日）**：
1. 省级边界已就位（见 1.3，`data/admin_boundaries.py` 提供分区几何与中英映射）
2. `nightlight_crawler.py` 新增 rasterio 分支：逐月栅格 × 省界 → 各省平均辐射值
3. 计算各省夜光环比变化 → 替换 WB 代理输出，数据可信度标记从"估算"升级为"官方"
4. 仪表盘多源融合视图自动受益（无需前端改动）

### 1.2 事件核密度分析（KDE）图层 ——【可立即开工】

**目标**：把风险地图从"省级平均"（一邦一个圆点）细化到"邦内热点走廊"，
直观呈现冲突沿边境口岸带状聚集等地缘态势。

**原理（一句话）**：每个事件是一个定位点，KDE 计算"哪里点堆得最厚"的
平滑密度面，堆得厚 = 地缘态势紧张。

**实施要点**：
1. `data/gdelt_files.py` 事件行补采经纬度字段（CSV 第 56/57 列 ActionGeo_Lat/Long，
   当前未保存，属于 10 行级改动）
2. `scipy.stats.gaussian_kde` 或 sklearn KernelDensity 计算密度面
   （带宽可用 Silverman 法则自适应）
3. 渲染方案二选一：folium HeatMap（已有依赖，快）或 栅格瓦片（更精细）
4. 与现有省级风险圆点叠加为双图层，图例注明"事件密度（KDE）"
5. **不依赖任何外部数据**——GDELT CSV 通道自带坐标

## 二、双边关系评估模块 ——【暂缓，方案已定】

**背景**：指导老师建议纳入中美等大国对缅关系维度。系统当前只监测
"缅甸国内发生了什么"，未度量"外部大国在缅甸做什么"。

**技术验证结论（实测）**：
- GDELT 事件文件含行为体国家对（Actor1/2CountryCode + Goldstein 分值），
  现有 CSV 通道零增量带宽即可提取
- ⚠️ 行为体国家码是 **ISO3（MMR/USA/CHN）**，不是 FIPS 的 BM
- 缅甸事件日均约 30 条，国家对样本需 7 天滚动窗口积累

**三层数据架构**：
```
政策层：Google News 政策查询组（"US Myanmar sanctions" 等，复用代理通道）
结构层：贸易依存度（data/static/bilateral_trade.json 人工精编 + 来源标注）
动态层：GDELT 国家对合作/冲突指数（复用 CSV 通道）
```

**分期**：
- 一期（约 1 日）：国家对提取 + `analyzer/bilateral.py` + `/api/bilateral` + 雷达卡片
- 二期（半天）：贸易精编数据接入雷达
- 三期（半天）：政策监测查询组 + 政策事件时间线
- 四期（可选）：LLM 政策解读、接入诊断归因

**取舍原则**：先作独立面板，不动已验证的五维权重；数据积累 2-4 周后
再评估是否作为新维度接入。回测锚点：2025 年 5 月美国部分解除制裁的政策拐点。
